## 一、修复内容

### 1. 阅读器操作区重做（`src/ui.js` Btn + `src/screens/Journal.js`）

**问题**：档案类文档底部「删除」按钮无 flex，缩成一小块贴在左下角；「问团团」按钮颜色渲染异常。

**方案**：建立明确的主次按钮体系——`Btn` 新增 `variant`（`solid` 实心主操作 / `ghost` 白底描边次操作）与 `icon` 支持：

| 场景 | 主操作（实心橙） | 次操作（白底描边） |
|---|---|---|
| 课程笔记 / 画像 | ✎ 编辑 | 💬 问团团（橙描边） |
| 编辑态 | ✓ 保存 | 取消（橙描边） |
| 档案（只读） | 💬 问团团 | 🗑 删除（**红描边，等宽 flex:1**） |

「我的」页「清空全部数据」同步改为红描边（高危但不咄咄逼人）。

**验证**：截图 r7-03（课程笔记：编辑实心+问团团描边等宽）、r7-04（档案：问团团+删除等宽，删除不再缩角）。

### 2. 记忆分层流转实证（`scripts/test-memory-flow.mjs` + 真机）

**Node harness（mock LLM 跑真代码状态机，12/12 断言通过）**：注入 70/20/2 天前记录 + 过期 dailies×8 + 过期 weeklies×3，跑 `nightlyMaintenance(true)`：

| 断言 | 结果 |
|---|---|
| 70 天记录 → 深冷（转写清空、提炼只留 title/summary） | ✅ |
| 20 天记录 → 转写瘦身 328 字 + 标记 | ✅ |
| 2 天记录 → 原样保留 | ✅ |
| 过期日结 → 压缩成周记（8 条 → `9.20-9.27`） | ✅ |
| 过期周记 → 压缩成月结（3 条 → `8.1-8.21`） | ✅ |
| 已压缩周记从列表移除（不重复留存） | ✅ |
| >7 天录音文件清理（uri 置空） | ✅ |
| 已掌握卡片降温归档 | ✅ |
| 缺失日结按天补齐 | ✅（顺带修复真 bug，见下） |

**真机（真 LLM）**：点「立即整理」→「整理中」→「整理完成：日结」，分层卡计数刷新（截图 r7-10）。

**修复的真 bug**：原 `maybeDailyRollup` 只生成「今天」的日结——某天没开 App，那天的日结永远缺失。现改为按天补齐（最多补 3 天防爆量）。

### 3. 编辑待办键盘遮挡（`src/ui.js` Sheet）

**方案**：Sheet 的 Modal 加 `statusBarTranslucent + navigationBarTranslucent`（Android Modal 键盘 resize 的标准解法），并把 `KeyboardAvoidingView`（Android `behavior="height"`）从 ScrollView 内部移到包住整个面板——键盘弹出时**整个面板包括保存按钮一起上浮**。

**验证**：截图 r7-05——键盘弹出后，待办内容输入框、截止时间 chips、自定义输入框、保存按钮全部可见可用。顺带验证 DDL 修改闭环：点「明天」chip → 保存 → 待办行出现橙色「明天到期」徽标。

### 4. 空会话不保留（`src/screens/Ask.js`）

`pruneEmpty(keepId)`：四个时机清理无消息会话（保留正在使用的）——启动时、切换会话时、关抽屉时、新建时（连点新建不留一串空白）。

**验证**：真机操作序列——新建会话（抽屉出现「新对话」）→ 切回旧会话 → 再开抽屉，「新对话」已消失（截图 r7-09）。
