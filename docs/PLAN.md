## 三、需要你提供的东西（按优先级）

1. **ASR API**（录音转文字，现在唯一断点）
   - 需要：长音频、中文、分句时间戳；说话人分离加分
   - 给我：base_url + key（讯飞/火山/腾讯/Whisper API 均可）
   - 用途：录音 → 文字 → 走已有 LLM 提炼管线 → 笔记
2. **LLM API**（已有 OpenRouter key 在用，可选替换）
   - 如要换私有部署/专用额度：OpenAI 兼容 base_url + key + 模型名，环境变量即换
3. **心力球设备协议**（接真机时才需要，不急）

   - B. 公网服务器（需要一个有公网 IP 的机器或内网穿透，手机随时随地用）
