# 团子 · 用户视角体验叙事（v2）

> 这份文档先于代码存在：从使用者「小满」的一天出发，写出她在每个触点**看到什么、期待什么、哪里会困惑**，
> 再由叙事推导产品规则。本轮修订由三个真实困惑驱动：日常被当成课程、知识卡片找不到了、编辑待办被键盘挡住。

## 小满是谁

大二女生，课多、社团忙、记性一般。她在手机上装了「团子」，用它录课、记事、攒复习卡。
她不关心 LLM、Agent、记忆分层这些词——她只关心三件事：**我的东西去哪了、我还能信它多久、我要改的时候改得动吗。**

## 她的一天

### 08:00 高数课 · 录音

点底部中央的录音键，球变红开始计时。她把手机扣在桌上听课。
下课点一下录音键，弹出控制面板：**完成 · 保存并整理**。

她的期待：*「东西收好了，回头我要用的时候找得到就行。」*

### 10:00 课间 · 看待办

今日页，「还图书馆的书」写着「今天到期」。她昨晚在图书馆说的，团团听进去了。
点行尾的「⋯」可以把截止改到周五——**她的备忘录她说了算**。

一个会让她烦躁的场景（本轮修复）：点「编辑」弹层后，**键盘把保存按钮挡住了**。
她的判断很简单：*「这功能没做完。」*——她不区分什么 Modal 独立窗口、什么 resize 模式。
→ 规则 A：**任何带输入的弹层，键盘弹出时内容必须完整可见，焦点在哪个输入框都一样。**

### 12:30 午饭 · 说了句碎念

「哎呀这周好累，下午还想睡。」团团记下来了，变成今日记录里一条「碎念」。

她晚上打开手帐，看到**课程笔记分组里躺着一个「日常」**——

> *「日常是什么课？我没有这门课啊。」*

这不是她的错。是团子把不属于任何课程的生活记录，塞进了「课程笔记」的抽屉。
→ 规则 B：**只有课程才叫课程。** 有课名归属的学习材料（高等数学、大学英语、管理学……）才进「课程笔记」分组；
> 生活记录归入**「日常随笔」**分组，不穿课程的衣服。
>
> 更重要的：**分类是她的，不是团子的。** 团子先猜，猜错了她要能改——
> 手帐里每个笔记都可以：**重命名**（把「日常」改成「心理学导论」，或反过来）、**删除**。
> 这就是控制权：AI 负责整理，她负责定义。

### 19:00 晚自习 · 复习卡片

她记得团子会做知识卡片——上周复习泰勒公式的翻卡很顺手。
但今天今日页翻了个遍，**没有卡片的影子**（昨天的卡按日失效了，今天还没录新课）。

> *「功能是不是没了？」*

功能还在，入口消失了——在她的世界里，**入口消失 = 功能消失**。
→ 规则 C：**复习卡片是常驻入口，不是「今日有新卡才出现」的彩蛋。**
> 有新卡：展示新卡 deck；没有新卡：显示「复习卡片 · N 张在册 · 去复习」，点开是全部在册卡片。
> 空的世界里不装作不存在——那是要她回来复习的钩子。

### 22:30 睡前 · 手帐

翻手帐：课程笔记按课分组、日常随笔单列、小结沉在下面、档案按日期折好。
她偶尔点「立即整理」，看团团把这一周收进周结——*像睡前收拾桌面的人。*

她看得到分层（工作/知识/沉淀），但不需要理解名词：**热的东西在今日，知识在笔记和卡片，旧的沉下去。**

## 由叙事推导的本轮改动

| 规则 | 改动 | 验收（真机） |
|---|---|---|
| A 弹层键盘 | Sheet 用 keyboardDidShow 手动抬升面板（Android Modal 是独立窗口，KAV 不可靠） | 编辑待办三个场景：autoFocus 弹键盘 / 收起再点下方自定义框 / 点 chips |
| B 课程控制权 | 「日常」键归入「日常随笔」分组；笔记卡新增 ⋯ 菜单：重命名 / 删除 | 手帐分组截图 + 重命名流程截图 |
| C 卡片常驻 | TodayCards 无新卡时显示在册入口；复习弹层展示全部在册卡 | 今日页截图（无新卡状态） |

## 设计基调（frontend-design pass）

- **词汇跟随用户**：界面上不出现「工作层/知识识层/L1/Agent」这类系统词；说「最近的记录」「课程笔记」「攒下的卡片」。
- **空状态是邀请**：没有新卡 → 「攒下的 12 张卡在等你」而不是空白消失。
- **视觉层级编码信息**：课程笔记=暖橙（学习材料），日常随笔=雾紫（生活面），小结=绿，月结=深紫——颜色即分组语义，不靠装饰。
- **克制**：新增的 ⋯ 入口与待办一致（同一动词「编辑/删除」），不发明新交互。
